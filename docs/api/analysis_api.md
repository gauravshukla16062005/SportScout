# Analysis API Documentation

## Endpoint

### Analyze Badminton Video

**Method:** POST

**Route:**

```http
/api/analyze
```

---

## Description

Uploads a badminton video and returns the complete analysis generated by the SportScout ML pipeline.

The analysis includes:

* Video metadata
* Feature extraction results
* Evaluation scores
* Recommendations
* Explainability report

---

## Request

### Content-Type

```http
multipart/form-data
```

### Body

| Field | Type | Required | Description           |
| ----- | ---- | -------- | --------------------- |
| video | File | Yes      | Input badminton video |

Example:

```text
video = badminton_match.mp4
```

---

---

## Error Responses

### Missing Video

```http
400 Bad Request
```

```json
{
  "error": "No video file provided."
}
```

### Invalid Video Format

```http
400 Bad Request
```

```json
{
  "error": "Unsupported video format."
}
```

### Internal Server Error

```http
500 Internal Server Error
```

```json
{
  "error": "Analysis failed."
}
```
